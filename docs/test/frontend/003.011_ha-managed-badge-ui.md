# Test Case: 003.011_ha-managed-badge-ui

## Test Objective

Verify the frontend Volumes page shows a "Managed by Home Assistant" badge for HA-managed partitions and hides mount/automount/format/label/unmount actions for those rows while keeping Create Share / Go to Share available.

## Preparation

1. Ensure the SRAT addon is running and the frontend dev server is reachable at `http://localhost:3080/`
2. Confirm at least one HA-managed partition exists (`is_ha_mounted: true` in `GET /api/volumes`)
3. Open the Volumes tab in the browser

**If any preparation step fails**, the test must be **skipped**.

## Execution

1. Navigate to the Volumes tab
2. Locate a partition row whose `is_ha_mounted` is true (use the volume details panel)
3. Assert a "Managed by Home Assistant" badge is visible for that partition
4. Assert the Mount button is NOT visible (or disabled with tooltip) for that partition
5. Assert Automount toggle is NOT visible for that partition
6. Assert Format / Check / Set Label actions are NOT visible for that partition
7. Assert Unmount action is NOT visible for that partition
8. Assert Create Share and Go to Share ARE still available

**Assertions:**

- Badge present for HA-managed rows
- Mount/automount/format/check/label/unmount hidden for HA-managed rows
- Create Share / Go to Share still present

## Validation

1. Check browser console for errors
2. Screenshot the volumes tab

**Success criteria:** Badge shown and HA-managed actions hidden while share actions remain.
