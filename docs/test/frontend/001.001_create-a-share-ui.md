# Test Case: 001.001_create-a-share-ui

## Test Objective

Verify that the frontend UI allows users to create a new SMB share with the required fields and validates input correctly.

## Preparation

1. Ensure the SRAT addon is running: `addon ls` - should show srat addon as `running`
2. Start Home Assistant frontend: ensure the UI is accessible at `http://localhost:8123`
3. Navigate to the Share Management page: `http://localhost:8123/srat/shares`
4. Verify the share creation form is loaded and displays fields: "Share Name", "Share Path", "Description"
5. Check that the form has an optional "subdirectory" field (if applicable)
6. Open browser developer tools and verify no JavaScript errors on page load

**If any preparation step fails** (addon not running, UI not accessible, form not loaded), the test must be **skipped**.

## Execution

1. Fill in the share creation form:
   - Share Name: `ui-test-share-$(date +%s)`
   - Share Path: `/mnt/testvolume`
   - Description: "Test share created via test case 001.001"
   - (Optional) subdirectory: `movies` (if field is displayed)
2. Select the "Create Share" submit button
3. Wait for the UI to show a success notification or toast message
4. Verify the new share appears in the shares list table

**Assertions:**
- Success notification/toast appears after share creation
- New share name `ui-test-share-*` appears in the shares list table
- Share path column shows `/mnt/testvolume`
- Form is reset after successful creation

## Validation

1. Verify the newly created share is accessible via the SRAT API:
   ```bash
   curl -s http://localhost:8090/api/shares | jq ".[].name" | grep "ui-test-share"
   ```
2. Confirm share details match what was entered in the form
3. Check that the share appears in the Home Assistant UI under Configure > Shares
4. Test that the share can be edited via the frontend UI
5. Test that the share can be deleted via the frontend UI

**Success criteria:** Share created via UI is verifiable through API and Home Assistant UI, and edit/delete operations work correctly.
