# Test Case: 004.001_users-tab-ui

## Test Objective

Verify Users tab loads correctly: left `UsersTreeView` groups (Administrators/Users), right details placeholder, WebSocket green, no console errors, and `localStorage` persistence of `users.selectedUserKey` / `users.expandedGroups`.

## Preparation

1. Addon running: `ha addons info local_sambanas2` → `started`; `curl -s http://192.168.0.68:3000/api/health` → 200
2. Verify users exist: `curl -s http://192.168.0.68:3000/api/users | jq -r '.[].username'` → at least `admin`; note count and sample usernames
3. Frontend served at `http://localhost:3080/` via `API_URL=http://192.168.0.68:3000/ SUPERVISOR_URL=http://192.168.0.68/ mise run //frontend:dev:remote` → `Bun.serve listening on :3080` and `bun tsc --noEmit` green
4. Clear localStorage baseline then reload: `localStorage.removeItem("users.selectedUserKey"); localStorage.removeItem("users.expandedGroups")` then reload `http://localhost:3080/`
5. Open devtools: `browser_console_messages` should have no uncaught errors after initial load

**If any preparation step fails** (addon down, no users, frontend not ready), **skip**.

## Execution

1. Navigate to `http://localhost:3080/` → wait for App shell; verify NavBar Tabs include `Users` (`#full-width-tab-?` or `getByRole('tab', {name:/users/i})`); click `Users` tab
2. Take screenshot → verify `Users` title in left panel (`getByText('Users')`) and tree view `aria-label="users tree view"` present via `browser_snapshot`
3. Expand groups: `browser_snapshot` → `SimpleTreeView` should show `group-admin` (Administrators) with count chip and `group-users` (Users) if any; verify via `document.querySelector('[aria-label="users tree view"]')` or React fiber if snapshot only shows `RootWebArea`
4. Verify right panel placeholder when no selection: `getByText('Select a user from the list to view details')` visible
5. Select a user: click `admin` leaf (`onUserSelect` → `selectedUserKey=admin`); verify `UserDetailsPanel` appears: `getByText('admin')` heading, `Chip` `Administrator` warning, avatar `AdminPanelSettingsIcon`, shares chips if any
6. Verify persistence: `localStorage.getItem('users.selectedUserKey')` → `admin`; `localStorage.getItem('users.expandedGroups')` → JSON array containing `group-admin`
7. Reload page → verify same user remains selected (selection restored from localStorage via `useEffect`); no flash of placeholder
8. Check WebSocket indicator in NavBar is green (connected) and `browser_network_requests` for `/api/users` returned 200

**Assertions:**

- Tab click navigates to Users, title and tree render, placeholder shown when deselected, details shown when selected
- localStorage keys set correctly and survive reload
- WS green, `/api/users` 200, no console errors

## Validation

1. Verify non-admin group sorting: if `group-users` has ≥2 users, check alphabetical order via `users.data` sorted `localeCompare`
2. Check console: `browser_console_messages` → no `ERROR` or `not wrapped in act` warnings
3. Check logs: `ha addons logs local_sambanas2 | tail -30` and `ha core logs | tail -20` → no new ERROR after UI navigation
4. Collapse/expand a group → `localStorage` updates accordingly

**Success criteria:** Tree renders grouped/sorted, selection persists, no UI or log errors.
