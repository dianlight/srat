# Test Case: 008.004_notification-badge-ignores

## Test Objective

Verify the header notification badge excludes server-ignored problems: ignoring the `protected_mode` alert drops the badge count (and its toast entry), and re-enabling restores it. Found during the 008.003 remote run: the dashboard card hid correctly after Ignore, but the NavBar badge still counted the ignored problem. If the badge still counts ignored problems, file it as a bug (expected: badge follows the same ignore semantics as the HA bridge) rather than failing the whole run.

## Preparation

1. Ensure the SRAT addon is running: `ha apps info local_sambanas2` → `started`; health 200
2. Ensure protection mode is ON and `protected_mode` problem is active with `ignored: false` (re-enable via API if needed)
3. Ensure frontend is served at `http://localhost:3080/` — page loads with no JS errors
4. Navigate to Dashboard (desktop viewport `1440x900`); complete the Setup Wizard first if it opens (see 008.002 step 5)
5. Baseline: record the header badge count next to the notification bell

**If any preparation step fails** (addon not running, UI not accessible, no active problem), the test must be **skipped**.

## Execution

1. On the Dashboard, click **Ignore** on the "Addon in Protected Mode" card → assert the card hides (with "Show Ignored" OFF)
2. Assert the header badge count decreases by one (ignored problems excluded); assert no toast entry for the ignored problem remains in the notification list
3. Toggle "Show Ignored" ON → click **Re-enable** → assert the card returns and the badge count is restored
4. Restore: leave the problem un-ignored (`ignored: false`) unless the suite baseline requires otherwise

**Assertions:**

- Badge count tracks only un-ignored problems (dashboard, badge, and HA bridge agree)
- Re-enable restores both card and badge without a restart
- No red error banner; console has no uncaught errors

## Validation

1. `GET /api/problems/protected_mode` → `ignored: false` (baseline state)
2. Check addon logs: `ha apps logs local_sambanas2 | tail -n 30 | grep -iE "panic|FATAL"` → empty
3. Confirm addon state `started` and health 200

**Success criteria:** Badge and card follow server ignore state symmetrically; if the badge diverges, a bug is filed with a screenshot and the case is marked fail with evidence.
