# Test Case: 011.002_rclone-cloud-sync-panel-ui

## Test Objective

Verify the lab-gated Cloud Sync section renders inside the volume details page and the link wizard opens, with hidden state when lab mode is OFF.

## Preparation

1. Ensure SRAT addon `local_sambanas2` is running and frontend dev server serves at `http://localhost:3080/` (started via `mise run //frontend:dev:remote`, baked `API_URL` verified as `http://192.168.0.68:3000/`).
2. Save pristine settings JSON (`GET /api/settings`) to restore exclusively from it.
3. Lab ON pass requires `experimental_lab_mode=true`; lab OFF pass requires `false` (toggle via Settings UI or PUT full object + addon restart).
4. Navigate to Volumes page; confirm at least one mounted volume row exists.

**If any preparation step fails**, the test must be **skipped** and documented in test logs.

## Execution

1. Lab ON: open a mounted volume details. **Assertion:** a "Cloud Sync"/"Cloud Link" section renders inline (not a separate tab); unlinked state shows `Link to cloud` button.
2. Click `Link to cloud`. **Assertion:** link wizard modal opens with 3 steps (Provider → Account → Remote folder); Dropbox offered; remote path defaults to `/srat/<volume-label>`; Cancel/Create link present.
3. Close wizard (Cancel/Escape). Open browser console messages. **Assertion:** no uncaught errors, no failed `/api/rclone/*` network calls beyond expected 4xx when unauthenticated.
4. Lab OFF: reload Volumes page, open the same volume details. **Assertion:** Cloud Sync section is hidden entirely.

## Validation

1. WebSocket status indicator in NavBar is green (connected) in both passes.
2. No red error banners on page load; console shows no new errors attributable to the panel.
3. Restore settings exclusively from pristine JSON if toggled; restart addon if settings changed.

**Success criteria:** Panel visible + wizard opens with lab ON, fully hidden with lab OFF, no console/network errors.
