# Test Case: 002.003_smart-test-lifecycle

## Test Objective

Verify the SMART self-test lifecycle on a SMART-capable disk: `POST /disk/{id}/smart/test/start` begins a short test, `GET .../smart/test` reports progress while running, and `POST .../smart/test/abort` returns the disk to idle. Non-destructive (short test + abort); never start a long/extended test on the test box.

## Preparation

1. Ensure the SRAT addon is running: `ha apps info local_sambanas2` → `started`; health 200
2. Pick a SMART-capable disk: `GET /api/volumes` → disk ids; `GET /api/disk/{id}/smart/health` → 200 for at least one disk → note `DISK_ID`. Known test-box caveat: USB bridges (`0x0bda:0x9210`, `0x090c:0x1000`, `0x048d:0x1234`) and `/dev/sda` (`Operation not permitted` in protection mode) may fail — try each disk in turn
3. If no disk returns SMART health 200, the test must be **skipped** (record which disks failed and why)
4. Baseline: `GET /api/disk/{DISK_ID}/smart/test` → note status (expect idle/none)

**If any preparation step fails** (addon not running, no SMART-capable disk), the test must be **skipped**.

## Execution

1. Start a short test: `POST /api/disk/{DISK_ID}/smart/test/start` with `{"type": "short"}` (check the OpenAPI schema for the exact field; never use long/extended) → expect 200/202
2. Poll `GET /api/disk/{DISK_ID}/smart/test` → assert status shows a test in progress (not idle) within 30 s
3. Abort: `POST /api/disk/{DISK_ID}/smart/test/abort` → expect 200
4. Poll `GET /api/disk/{DISK_ID}/smart/test` → assert back to idle (allow up to 60 s for the drive to settle)
5. Confirm `GET /api/disk/{DISK_ID}/smart/health` still 200 (no SMART stack wedged by the abort)

**Assertions:**

- Start → in-progress → abort → idle transition observed via the API
- No `panic`/`FATAL` in addon logs; SMART health endpoint healthy afterwards
- No extended/long test was ever started (audit the request payloads in evidence)

## Validation

1. Check addon logs: `ha apps logs local_sambanas2 | tail -n 30 | grep -iE "panic|FATAL"` → empty
2. Final `GET /api/disk/{DISK_ID}/smart/test` → idle; health 200
3. Confirm addon state `started` and health 200

**Success criteria:** Full short-test lifecycle completes and settles to idle with logs clean; skip (with per-disk evidence) if the box has no SMART-capable disk.
