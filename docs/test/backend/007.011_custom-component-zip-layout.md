# Test Case: 007.011_custom-component-zip-layout

## Test Objective

Verify the embedded `srat.zip` archive has integration files at the archive root (HACS `zip_release` layout) and that the internal install/upgrade path correctly places files under `custom_components/srat/`.

## Preparation

1. Addon running: `ha addons info local_sambanas2` → `state: started`
2. Health check: `curl -s http://192.168.0.68:3000/api/health` → 200
3. Lab mode on: `curl -s http://192.168.0.68:3000/api/lab_features | jq .ha_custom_component.available` → `true`; if not, `PUT /api/settings` with `experimental_lab_mode:true`
4. Record baseline: `curl -s http://192.168.0.68:3000/api/settings/homeassistant/custom-component/status | jq .installed` → note `BASE_INSTALLED`

**If any preparation fails** (health not 200, lab feature unavailable), **skip**.

## Execution

1. **Zip layout check:** `docker exec app_local_sambanas2 sh -c "cd /tmp && unzip -l /usr/local/bin/srat-server 2>/dev/null || true"` — instead, use the upgrade dir: `ssh root@192.168.0.68 'unzip -l /mnt/data/supervisor/app_configs/local_sambanas2/upgrade/srat.zip 2>/dev/null | head -20'` — verify `manifest.json` is at root (no `srat/` prefix)
2. **Internal install:** `curl -s -X POST http://192.168.0.68:3000/api/settings/homeassistant/custom-component/install -o /dev/null -w '%{http_code}\n'` → 200
3. **Filesystem verification:** `docker exec app_local_sambanas2 ls /homeassistant/custom_components/srat/manifest.json` → exists; `docker exec app_local_sambanas2 ls /homeassistant/custom_components/srat/__init__.py` → exists
4. **No nested dir:** `docker exec app_local_sambanas2 ls /homeassistant/custom_components/srat/srat/manifest.json` → must NOT exist (no nested `srat/` directory)
5. **Status check:** `curl -s http://192.168.0.68:3000/api/settings/homeassistant/custom-component/status | jq .installed` → `true`

**Assertions:**

- Zip archive contains `manifest.json` at root level
- After install, `custom_components/srat/manifest.json` exists
- No `custom_components/srat/srat/` nested directory
- Status endpoint reports `installed: true`

## Validation

1. **Upgrade path:** `curl -s -X POST http://192.168.0.68:3000/api/settings/homeassistant/custom-component/upgrade -o /dev/null -w '%{http_code}\n'` → 200; re-verify filesystem layout (no nested dir)
2. **Uninstall cleanup:** `curl -s -X DELETE http://192.168.0.68:3000/api/settings/homeassistant/custom-component -o /dev/null -w '%{http_code}\n'` → 200; `docker exec app_local_sambanas2 ls /homeassistant/custom_components/srat` → must not exist
3. **Restore baseline:** if `BASE_INSTALLED` was `true`, re-install; if `false`, leave uninstalled
4. Logs: `ha addons logs local_sambanas2 | tail -30` → no `panic`/`FATAL`

**Success criteria:** Zip has root-level manifest, internal install works without nested directory, upgrade succeeds, cleanup restores baseline.
