# Test Case: 010.003_ingress-proxy-session-enforcement

## Test Objective

Verify the Supervisor ingress proxy (not the addon) enforces session validity: bogus sessions 401, and the addon token cannot mint sessions or call `validate_session` (documents Task-3 wont-do live).

## Preparation

1. Addon started, door state per suite plan (proxy behavior is door-independent)
2. HA frontend base: lab HA is HTTPS on 443 with self-signed cert (`curl -sk https://192.168.0.68/ → 200`); port 8123 is NOT listening — do not use it
3. Supervisor token: `TOKEN=$(docker exec app_local_sambanas2 printenv SUPERVISOR_TOKEN)`

**If any preparation step fails** (HA HTTPS unreachable, no token), **skip**.

## Execution

1. **Bogus session via proxy:** `curl -sk 'https://192.168.0.68/api/hassio_ingress/BOGUSSESSION123/api/health' -o /dev/null -w '%{http_code}\n'` → 401 (Supervisor rejects before forwarding)
2. **Addon-side validate_session:** `docker exec app_local_sambanas2 curl -s -X POST -H "Authorization: Bearer $TOKEN" http://supervisor/ingress/validate_session -H 'Content-Type: application/json' -d '{"session":"dummy"}' -w 'HTTP:%{http_code}\n'` → `401 Unauthorized` with a token that returns 200 on `/supervisor/info` (control) — proves `@require_home_assistant`; addon-side re-validation not viable
3. **Valid-session passthrough:** requires HA user auth to mint a session; NOT performable with addon token alone — record as untested-live (covered by task-004 smoke 2026-09-21) unless HA credentials are available, then `GET https://192.168.0.68/api/hassio_ingress/<session>/api/health` → 200

**Assertions:**

- Bogus session → 401 from proxy
- `validate_session` → 401 with valid addon token; `/supervisor/info` → 200 with same token
- No valid session available without HA user auth → step 3 skipped with reason when creds absent

## Validation

1. Record status codes + bodies (17-byte `401: Unauthorized` for bogus)
2. Confirm no addon-log errors correlate with these probes

**Success criteria:** Proxy 401s invalid sessions; addon token limits reproduced; valid-session gap explicitly recorded, not guessed.
