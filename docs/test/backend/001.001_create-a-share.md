# Test Case: 001.001_create-a-share

## Test Objective

Verify that a new SMB share can be created successfully via the SRAT API and that the share configuration is properly rendered in `smb.conf`.

## Preparation

1. Ensure the SRAT addon is running: `addon ls` - should show srat addon as `running`
2. Verify a data disk is mounted and accessible: `df -h` - should show at least one mounted volume under `/mnt/`
3. Check existing shares configuration: `testparm -s /etc/samba/smb.conf` - note current share count
4. Set up test environment variables:
   ```bash
   export SRAT_TEST_MODE=true
   export TEST_SHARE_NAME="test-share-$(date +%s)"
   ```
5. Verify API endpoint is accessible: `curl -s http://localhost:8090/api/shares | jq '.')` - should return JSON array

**If any preparation step fails**, the test must be **skipped** and documented in test logs.

## Execution

1. Create a new share via API:
   ```bash
   curl -X POST http://localhost:8090/api/shares \
     -H "Content-Type: application/json" \
     -d "{\"name\": \"${TEST_SHARE_NAME}\", \"path\": \"/mnt/testvolume\", \"description\": \"Test share created via test case 001.001\"}"
   ```
2. Verify API response returns HTTP 201 Created
3. Verify share was created in Samba config:
   ```bash
   testparm -s /etc/samba/smb.conf | grep -A5 "${TEST_SHARE_NAME}"
   ```
4. Verify `smb.conf` contains the new share entry with `path = /mnt/testvolume`

**Assertions:**
- API returns status code 201
- `smb.conf` contains new share with correct path
- Share appears in share listing: `curl -s http://localhost:8090/api/shares | jq ".[].name"` includes `${TEST_SHARE_NAME}`

## Validation

1. Verify share is listed in the SRAT frontend UI at `http://localhost:8090/shares`
2. Confirm share properties match what was created:
   - Share name matches `TEST_SHARE_NAME`
   - Share path matches `/mnt/testvolume`
   - Share description matches test description
3. Run integration test to verify share is accessible via Samba client
4. Clean up: remove test share via API `DELETE http://localhost:8090/api/shares/${TEST_SHARE_NAME}`

**Success criteria:** All assertions pass and share is confirmed created and then cleaned up.
