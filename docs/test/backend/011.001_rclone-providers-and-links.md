# Test Case: 011.001_rclone-providers-and-links

## Test Objective

Verify rclone Cloud Sync lab backend: providers list, link CRUD, diff dry path and sync dry-run with abort, all lab-gated.

## Preparation

1. Ensure SRAT addon `local_sambanas2` is running on `192.168.0.68`.
2. Enable lab mode: `GET /api/settings` shows `experimental_lab_mode=true`. If false, `PUT /api/settings` merging full object with `experimental_lab_mode=true`, then restart addon and re-verify.
3. Verify at least one mounted volume exists: `docker exec app_local_sambanas2 curl -sL http://localhost:64289/api/volumes` shows a mount with `is_mounted=true`. Record its `mount_point` as `TARGET_ID` (`target_kind=volume`).
4. Record pristine settings JSON to `/tmp/srat-orig-settings.json` for restore.

**If any preparation step fails**, the test must be **skipped** and documented in test logs.

## Execution

1. Providers (lab-gated):
   ```bash
   docker exec app_local_sambanas2 curl -s -o /dev/null -w '%{http_code}\n' 'http://localhost:64289/api/rclone/providers'
   ```
   **Assertion:** HTTP 200 with lab ON (`library_available` boolean, `dropbox` in drivers list). With lab OFF expect 403 `dto.ErrorLabModeRequired`.
2. Link CRUD (query-param identity — mount paths contain slashes):
   ```bash
   docker exec app_local_sambanas2 curl -s 'http://localhost:64289/api/rclone/links'
   docker exec app_local_sambanas2 curl -s -X PUT 'http://localhost:64289/api/rclone/link?target_kind=volume&target_id=<TARGET_ID>' -H 'Content-Type: application/json' -d '{"provider":"dropbox","remote_path":"/srat/manual-test","auto_sync":false,"schedule_minutes":0}'
   docker exec app_local_sambanas2 curl -s 'http://localhost:64289/api/rclone/link?target_kind=volume&target_id=<TARGET_ID>'
   ```
   **Assertions:** links list 200; PUT 200/201; GET returns `provider=dropbox`, `status` in `unlinked|authorized`.
3. Diff (no credentials needed for contract check):
   ```bash
   docker exec app_local_sambanas2 curl -s -X POST 'http://localhost:64289/api/rclone/link/diff?target_kind=volume&target_id=<TARGET_ID>'
   ```
   **Assertion:** HTTP 200 with entries array OR 4xx/5xx with typed error when remote unreachable — either way response is JSON, no panic in addon logs.
4. Sync dry-run + abort (side-effect free by contract):
   ```bash
   docker exec app_local_sambanas2 curl -s -X POST 'http://localhost:64289/api/rclone/link/sync?target_kind=volume&target_id=<TARGET_ID>' -H 'Content-Type: application/json' -d '{"direction":"push","dry_run":true}'
   docker exec app_local_sambanas2 curl -s -X POST 'http://localhost:64289/api/rclone/link/abort?target_kind=volume&target_id=<TARGET_ID>'
   ```
   **Assertions:** sync accepts (200/202); abort 200; `rclone_task` WS event emitted (`status=start|running|success|failure`); dry-run raises no Problem.

## Validation

1. Re-read addon logs: no `FATAL`/`panic`, no new `ERROR` correlating with the calls.
2. Cleanup: `DELETE /api/rclone/link?target_kind=volume&target_id=<TARGET_ID>` returns 200/204; follow-up GET returns 404.
3. Restore settings exclusively from pristine JSON if mutated.

**Success criteria:** Providers 200, CRUD round-trip works, diff/sync-dry-run return typed responses, no problems raised for dry-run, cleanup verified.
