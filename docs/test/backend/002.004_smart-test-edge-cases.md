# Test Case: 002.004_smart-test-edge-cases

## Test Objective

Verify SMART self-test edge-case behavior on a SMART-capable disk: a second `POST /disk/{id}/smart/test/start` while a test runs is rejected with 422, `POST .../smart/test/abort` on an idle drive succeeds without side effects, and `GET .../smart/health` agrees with ground-truth `smartctl -H`. Non-destructive (short tests only); never start a long/extended test on the test box.

## Preparation

1. Ensure the SRAT addon is running: `ha apps info local_sambanas2` → `started`; health 200
2. Pick a SMART-capable disk: `GET /api/volumes` → disk ids; `GET /api/disk/{id}/smart/health` → 200 for at least one disk → note `DISK_ID`. Known test-box caveat: USB bridges (`0x0bda:0x9210`, `0x090c:0x1000`, `0x048d:0x1234`) may fail — try each disk in turn
3. If no disk returns SMART health 200, the test must be **skipped** (record which disks failed and why)
4. Baseline: `GET /api/disk/{DISK_ID}/smart/test` → note status (expect not running)

**If any preparation step fails** (addon not running, no SMART-capable disk), the test must be **skipped**.

## Execution

1. Start a short test: `POST /api/disk/{DISK_ID}/smart/test/start` with `{"test_type": "short"}` (check the OpenAPI schema for the exact field; never use long/extended) → expect 200
2. Immediately start again: `POST /api/disk/{DISK_ID}/smart/test/start` with `{"test_type": "short"}` → expect 422 (test already in progress)
3. Abort: `POST /api/disk/{DISK_ID}/smart/test/abort` → expect 200
4. Abort again on the now-idle drive: `POST /api/disk/{DISK_ID}/smart/test/abort` → expect 200 and `GET .../smart/test` still shows running false
5. Ground truth: `smartctl -H` on the drive device in the addon container → compare PASSED/FAILED with `GET /api/disk/{DISK_ID}/smart/health` (`passed` field must agree)

**Assertions:**

- Second start while running → 422, and only one test ran on the drive
- Abort on idle → 200 with no side effects (still not running)
- API health `passed` agrees with `smartctl -H` (both PASSED or both FAILED)
- No extended/long test was ever started (audit the request payloads in evidence)

## Validation

1. Check addon logs: `ha apps logs local_sambanas2 | tail -n 30 | grep -iE "panic|FATAL"` → empty
2. Final `GET /api/disk/{DISK_ID}/smart/test` → running false; health 200
3. Confirm addon state `started` and health 200

**Success criteria:** Double-start rejected with 422, idle abort harmless, health agrees with smartctl, logs clean; skip (with per-disk evidence) if the box has no SMART-capable disk.
