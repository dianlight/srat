# Test Case: 004.001_users-crud-api

## Test Objective

Verify Users CRUD via SRAT backend API: list users, create user, duplicate rejected, edit user (password + shares), delete user, and that Samba password is enforced via `pdbedit` / `smbclient`.

## Preparation

1. Ensure addon running: `ha addons info local_sambanas2` → `started`; `curl -s http://192.168.0.68:3000/api/health` → 200
2. Verify at least one share exists for assignment: `curl -s http://192.168.0.68:3000/api/shares | jq -r '.[].name'` → non-empty; if empty create via `001.001` free-partition flow
3. Capture baseline: `curl -s http://192.168.0.68:3000/api/users | jq '.'` → note `TEST_BASE_COUNT`; ensure `admin` user present with `is_admin:true`
4. Generate unique test identity: `TEST_USER="testu$(date +%s | tail -c 5)"` (kebab/lower, ≤12 chars, matches `^[a-zA-Z0-9 _-]+$`); `TEST_PASS="TestPass$(date +%s | tail -c 4)!"` (≥4 chars); `export TEST_USER TEST_PASS`
5. Ensure no leftover: `curl -s http://192.168.0.68:3000/api/users | jq -r --arg u "$TEST_USER" '.[] | select(.username==$u) | .username'` → empty; if present `curl -X DELETE http://192.168.0.68:3000/api/user/$TEST_USER` → 200/404 then re-check

**If any preparation step fails** (API unreachable, no shares, admin missing), **skip** and document.

## Execution

1. **List (GET /users):** `curl -s http://192.168.0.68:3000/api/users | jq -e 'length >=1 and (map(select(.is_admin)) | length >=1)'` → true; each entry has `username` string and `is_admin` bool
2. **Create (POST /user):** 
   ```bash
   curl -s -w "\n%{http_code}" -X POST http://192.168.0.68:3000/api/user \
     -H "Content-Type: application/json" \
     -d "{\"username\":\"$TEST_USER\",\"password\":\"$TEST_PASS\",\"is_admin\":false}"
   # expect 201 and body username==$TEST_USER
   ```
   Verify via GET: `curl -s http://192.168.0.68:3000/api/users | jq -r --arg u "$TEST_USER" '.[] | select(.username==$u) | .username'` → `$TEST_USER`
3. **Duplicate rejected:** repeat same POST → expect 409 (or 4xx) with detail containing `already exists`
4. **Empty password rejected:** `curl -s -w "\n%{http_code}" -X POST http://192.168.0.68:3000/api/user -H "Content-Type: application/json" -d "{\"username\":\"${TEST_USER}2\",\"password\":\"\"}"` → expect 422 (ErrorPasswordRequired)
5. **Edit user (PUT /user/{username}):** update password + share assignments:
   ```bash
   SHARE=$(curl -s http://192.168.0.68:3000/api/shares | jq -r '.[0].name')
   curl -s -X PUT http://192.168.0.68:3000/api/user/$TEST_USER \
     -H "Content-Type: application/json" \
     -d "{\"username\":\"$TEST_USER\",\"password\":\"NewPass123!\",\"rw_shares\":[\"$SHARE\"]}" | jq .
   # expect 200 and rw_shares contains SHARE
   ```
   Verify via GET: `curl -s http://192.168.0.68:3000/api/users | jq --arg u "$TEST_USER" '.[] | select(.username==$u) | {rw_shares,is_admin}'`
6. **Samba enforcement:** inside addon `docker exec addon_local_sambanas2 pdbedit -L | grep -q $TEST_USER` → found; `docker exec addon_local_sambanas2 smbclient -L //127.0.0.1 -U $TEST_USER%NewPass123!` → list includes shares (or `NT_STATUS_OK`); with wrong pass `docker exec addon_local_sambanas2 smbclient -L //127.0.0.1 -U $TEST_USER%WrongPass` → `NT_STATUS_LOGON_FAILURE`
7. **Delete (DELETE /user/{username}):** `curl -s -w "\n%{http_code}" -X DELETE http://192.168.0.68:3000/api/user/$TEST_USER` → 200; verify `GET /users` no longer contains `$TEST_USER`; `docker exec addon_local_sambanas2 pdbedit -L | grep $TEST_USER` → not found
8. **Delete non-existent:** `curl -s -w "\n%{http_code}" -X DELETE http://192.168.0.68:3000/api/user/$TEST_USER` → 404

**Assertions:**
- Create returns 201, GET finds user, duplicate 409, empty password 422, edit 200, delete 200, second delete 404
- Samba `pdbedit` and `smbclient` confirm password lifecycle

## Validation

1. Re-list users: `curl -s http://192.168.0.68:3000/api/users | jq length` → equals `TEST_BASE_COUNT` (cleanup restored baseline)
2. Check addon logs for ERROR: `ha addons logs local_sambanas2 | tail -n 50 | grep -iE "ERROR|panic|FATAL"` → no new errors correlating to user actions
3. Check core logs for user handler errors: `ha core logs | grep -i "users" | tail -20`
4. Verify `smb.conf` not corrupted: `docker exec addon_local_sambanas2 testparm -s 2>&1 | head -20` → no `ERROR`

**Success criteria:** All assertions pass, no log errors, baseline restored after delete.
